# JavaFX Calculator

A calculator application built using Java and JavaFX.

## About

This project is a graphical calculator that allows users to perform basic arithmetic operations through an interactive interface.

## Features

- Addition, subtraction, multiplication, and division
- Clear Entry (CE) and Clear (C) functionality
- Backspace to delete the last entered character
- Positive/negative number toggle
- Decimal number support
- Memory operations for storing and recalling values

## Technologies Used

- Java
- JavaFX

## How to Run

1. Clone or download this repository.
2. Open the project in IntelliJ IDEA.
3. Allow IntelliJ to configure the project and download any required dependencies.
4. Locate the HelloApplication.java file
5. Run the application.
